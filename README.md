# StudyOS Native — Android only

Class 10 CBSE study planner built with Flutter. Features include a flexible school/tuition routine planner, 25-minute focus timer, local notes, and CBSE/NCERT/video resource links.

For phone-only APK build instructions, read `README-ANDROID-ONLY.md`. The included GitHub Actions workflow compiles the APK in the cloud. No precompiled APK is included yet.
